# MapControls

Pila vertical de botones de 36px para el mapa: zoom, encuadrar zona, pantalla completa y medir.

Van a la derecha, bajo el LayerSwitcher. Los grupos se separan 8px. Cada botón tiene `aria-label` y `title`. En el inventario se omite «Medir» (`extra={false}`). Reemplaza el estilo de `.leaflet-bar`: fondo `surface`, borde `line-strong` y hover `unam-blue-tint`.
