# Badge

Etiqueta corta para estado, tipo de zona o clase de flujo.

Para clases de flujo, `flux={1..5}` (o `low`/`mid`/`high` = 1/3/5) muestra un punto del color de la clase junto a texto `ink`; el texto nunca va sobre el relleno de color. Usa `neutral` para la entidad federativa, `blue` para el tipo de sistema y `gold` para avisos editoriales.
